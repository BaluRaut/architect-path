# Architecture decision records

One file per decision, numbered, never edited after acceptance. A decision that turns
out wrong gets a new record that supersedes the old one, and the old one stays.

That last rule is the whole value. The record of a decision that was reasonable at the
time and wrong in hindsight is worth more than a tidy document that only ever contained
the right answers.

Copy [template.md](template.md) and number it.
